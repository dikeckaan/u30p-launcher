# U30P Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ZTE MU5358 (U30 Pro) cihazının 240×240 yuvarlak ekranı için, UFI-TOOLS bağımlılığı olmayan, ölçülebilir şekilde hafif bir native launcher yazmak.

**Architecture:** Tek `Activity`, sayfalar `Canvas`'a çizen custom `View`'lar. Veri kaynakları (telefon, batarya, `/proc/net/dev`, root shell) `DataHub`'da toplanıp immutable `Snapshot` üretir; snapshot değişmediyse yeniden çizim yapılmaz. Saf mantık (formatlama, parse, sayaç devri) `core/` altında Android bağımlılığı olmadan durur ve JVM'de test edilir.

**Tech Stack:** Kotlin 2.4.10 · Android SDK 35 · hiçbir kütüphane yok (AndroidX dahil) · Gradle yok — aapt2 / kotlinc / R8 / zipalign / apksigner ile elle derleme.

## Global Constraints

- Paket adı: `com.kaandikec.u30plauncher`
- minSdk 33, targetSdk 35, compileSdk 35 (`android.jar` API 35)
- **Hiçbir üçüncü parti bağımlılık yok** — AndroidX, Material, Compose kullanılmayacak
- `core/` altındaki hiçbir dosya `android.*` import etmeyecek (JVM'de test edilebilirliğin şartı)
- `onDraw` içinde allocation yapılmayacak: `Paint`, `Rect`, `StringBuilder` önceden ayrılır; `String.format` kullanılmaz
- Ekran 240×240 px @ density 160 → **1 dp = 1 px**; tüm koordinatlar doğrudan px olarak yazılır
- Yuvarlak ekran: merkez (120, 120), yarıçap 120. Köşeler görünmez
- Renkler: arka plan `#000000`, birincil `#FFFFFF`, sönük `#8A8A8E`, daha sönük `#5A5A5F`, indirme `#34C759`, yükleme `#0A84FF`, uyarı `#FF9F0A`, hata `#FF453A`, track `#26262A`
- **Faz 1 boyunca `cmd package set-home-activity` çağrılmayacak, Magisk modüllerine dokunulmayacak.** Manifest'te `android.intent.category.HOME` **yok**, yalnızca `LAUNCHER` var
- Cihaza her kurulumdan sonra doğrulama: ekranı `adb shell input keyevent KEYCODE_WAKEUP` ile uyandır, `adb exec-out screencap -p` ile görüntü al
- Her task sonunda commit

```bash
#!/usr/bin/env bash
set -euo pipefail

SDK="${ANDROID_HOME:-$HOME/Library/Android/sdk}"
BT="$SDK/build-tools/35.0.1"
PLATFORM="$SDK/platforms/android-35/android.jar"
KOTLIN_LIB="/opt/homebrew/opt/kotlin/libexec/lib"
STDLIB="$KOTLIN_LIB/kotlin-stdlib.jar"

OUT=build
APK="$OUT/u30p-launcher.apk"
KS="$OUT/debug.keystore"

rm -rf "$OUT"; mkdir -p "$OUT/classes" "$OUT/dex"

echo "==> kotlinc"
find src -name '*.kt' > "$OUT/sources.txt"
kotlinc -nowarn -jvm-target 11 -classpath "$PLATFORM" \
        -d "$OUT/classes" @"$OUT/sources.txt"

echo "==> R8"
java -cp "$BT/lib/d8.jar" com.android.tools.r8.R8 \
     --release --min-api 33 \
     --lib "$PLATFORM" \
     --pg-conf proguard.txt \
     --output "$OUT/dex" \
     $(find "$OUT/classes" -name '*.class') "$STDLIB"

echo "==> aapt2 link"
"$BT/aapt2" link \
    --manifest AndroidManifest.xml \
    -I "$PLATFORM" \
    --min-sdk-version 33 --target-sdk-version 35 \
    -o "$OUT/base.apk"

echo "==> add dex"
(cd "$OUT/dex" && zip -q -X "../base.apk" classes*.dex)

echo "==> zipalign"
"$BT/zipalign" -f -p 4 "$OUT/base.apk" "$APK"

if [ ! -f "$KS" ]; then
    echo "==> keystore"
    keytool -genkeypair -keystore "$KS" -alias u30p -storepass android \
            -keypass android -keyalg RSA -keysize 2048 -validity 10000 \
            -dname "CN=U30P,O=kaandikec,C=TR" >/dev/null 2>&1
fi

echo "==> sign"
"$BT/apksigner" sign --ks "$KS" --ks-pass pass:android --key-pass pass:android \
                --min-sdk-version 33 "$APK"

echo "==> ok: $APK ($(du -h "$APK" | cut -f1))"
```

```kotlin
object TestSupport {
    private var total = 0

    fun <T> eq(name: String, actual: T, expected: T) {
        total++
        if (actual != expected) {
            failed++
            println("FAIL  $name\n        beklenen: <$expected>\n        gelen:    <$actual>")

    fun ok(name: String, cond: Boolean) = eq(name, cond, true)

    fun report(): Int {
        println("\n$total test, $failed başarısız")
        return if (failed == 0) 0 else 1
    }
```

```kotlin
package com.kaandikec.u30plauncher.core

/**
 * Sıcak yolda allocation yapmadan sayı formatlar.
 *
 * `appendXxx` fonksiyonları çağıranın verdiği StringBuilder'a yazar; ara String
 * üretmez. String döndüren varyantlar yalnızca test içindir.
 */
object Fmt {
    private val BYTE_UNITS = arrayOf("B", "KB", "MB", "GB", "TB")
    private val BIT_UNITS = arrayOf("bps", "Kbps", "Mbps", "Gbps", "Tbps")

    /** Ondalık basamak sayısı: büyüdükçe azalır, böylece genişlik sabit kalır. */
    private fun decimalsFor(v: Double, unitIndex: Int): Int =
        if (unitIndex == 0) 0 else if (v < 10.0) 2 else if (v < 100.0) 1 else 0

    private fun appendDec(sb: StringBuilder, scaled: Long, decimals: Int) {
        when (decimals) {
            0 -> sb.append(scaled)
            1 -> {
                sb.append(scaled / 10); sb.append('.'); sb.append(scaled % 10)
            }
            else -> {
                sb.append(scaled / 100); sb.append('.')
                val f = scaled % 100
                if (f < 10) sb.append('0')
                sb.append(f)
            }
        }
    }

    /** Değeri uygun birime indirger; birim indeksini döndürür, sayıyı sb'ye yazar. */
    private fun appendScaledValue(sb: StringBuilder, value: Long, base: Double, unitCount: Int): Int {
        var v = if (value > 0) value.toDouble() else 0.0
        var i = 0
        while (v >= base && i < unitCount - 1) {
            v /= base
            i++
        }
        val d = decimalsFor(v, i)
        var pow = 1L
        repeat(d) { pow *= 10 }
        appendDec(sb, Math.round(v * pow), d)
        return i
    }

    private fun unitIndexOf(value: Long, base: Double, unitCount: Int): Int {
        var v = if (value > 0) value.toDouble() else 0.0
        var i = 0
        while (v >= base && i < unitCount - 1) {
            v /= base
            i++
        }
        return i
    }

    fun appendBytes(sb: StringBuilder, bytes: Long) {
        val i = appendScaledValue(sb, bytes, 1024.0, BYTE_UNITS.size)
        sb.append(' ')
        sb.append(BYTE_UNITS[i])
    }

    /** bytes/sn → bit/sn çevirip yalnızca sayıyı yazar (birim ayrı çizildiği için). */
    fun appendSpeedValue(sb: StringBuilder, bytesPerSec: Long) {
        val bits = if (bytesPerSec > 0) bytesPerSec * 8 else 0L
        appendScaledValue(sb, bits, 1000.0, BIT_UNITS.size)
    }

    fun speedUnit(bytesPerSec: Long): String {
        val bits = if (bytesPerSec > 0) bytesPerSec * 8 else 0L
        return BIT_UNITS[unitIndexOf(bits, 1000.0, BIT_UNITS.size)]
    }

    // --- yalnızca test için ---
    fun bytes(b: Long): String = StringBuilder().also { appendBytes(it, b) }.toString()
    fun speedValueOf(bytesPerSec: Long): String =
        StringBuilder().also { appendSpeedValue(it, bytesPerSec) }.toString()
    fun speed(bytesPerSec: Long): String = speedValueOf(bytesPerSec) + " " + speedUnit(bytesPerSec)
}
```

```kotlin
package com.kaandikec.u30plauncher.core

/** Tek bir arayüzün sayaçları. Yeniden kullanılır — her okumada yeniden ayrılmaz. */
class IfCounters {
    var rx: Long = 0
    var tx: Long = 0
}

/**
 * `/proc/net/dev` içeriğini String üretmeden ayrıştırır.
 *
 * Satır düzeni (iki nokta sonrası): rx alanları 0..7, tx alanları 8..15.
 * Yani rx bytes = alan 0, tx bytes = alan 8.
 */
object ProcNetParser {
    fun parse(buf: ByteArray, len: Int, iface: String, out: IfCounters): Boolean {
        var i = 0
        while (i < len) {
            val lineEnd = lineEndFrom(buf, i, len)
            if (matchIface(buf, i, lineEnd, iface)) {
                return readCounters(buf, i, lineEnd, out)
            }
            i = lineEnd + 1
        }
        return false
    }

    private fun lineEndFrom(buf: ByteArray, start: Int, len: Int): Int {
        var e = start
        while (e < len && buf[e] != '\n'.code.toByte()) e++
        return e
    }

    /** Satır başındaki boşlukları atlayıp `iface:` tam eşleşmesi arar. */
    private fun matchIface(buf: ByteArray, start: Int, end: Int, iface: String): Boolean {
        var p = start
        while (p < end && buf[p] == ' '.code.toByte()) p++
        for (k in iface.indices) {
            if (p + k >= end) return false
            if (buf[p + k] != iface[k].code.toByte()) return false
        }
        val after = p + iface.length
        return after < end && buf[after] == ':'.code.toByte()
    }

    private fun readCounters(buf: ByteArray, start: Int, end: Int, out: IfCounters): Boolean {
        var p = start
        while (p < end && buf[p] != ':'.code.toByte()) p++
        if (p >= end) return false
        p++

        var field = 0
        var rx = -1L
        var tx = -1L
        while (p < end) {
            while (p < end && buf[p] == ' '.code.toByte()) p++
            if (p >= end) break
            var v = 0L
            var digits = 0
            while (p < end) {
                val b = buf[p]
                if (b < '0'.code.toByte() || b > '9'.code.toByte()) break
                v = v * 10 + (b - '0'.code.toByte())
                digits++
                p++
            }
            if (digits == 0) {
                // sayı olmayan bir belirteç — satır beklediğimiz biçimde değil
                return false
            }
            if (field == 0) rx = v
            if (field == 8) { tx = v; break }
            field++
        }
        if (rx < 0 || tx < 0) return false
        out.rx = rx
        out.tx = tx
        return true
    }
}
```

```kotlin
package com.kaandikec.u30plauncher.core

/**
 * Kalıcı trafik sayaçlarının durumu. `lastTotal` = arayüzün en son okunan
 * kümülatif byte değeri; deltayı bundan çıkarırız.
 */
class UsageState {
    var dayKey: Int = -1
    var monthKey: Int = -1
    var dayBytes: Long = 0
    var monthBytes: Long = 0
    var lastTotal: Long = -1
}

object UsageCalc {
    /**
     * Yeni kümülatif toplamı işler.
     *
     * - İlk çağrıda yalnızca taban kurulur (geçmiş trafiği bugüne yazmayalım).
     * - `total < lastTotal` ise sayaç sıfırlanmıştır (reboot / arayüz yeniden
     *   kurulmuş); delta ham `total` olur.
     * - Devir kontrolü delta eklenmeden ÖNCE yapılır, aksi halde yeni günün
     *   ilk deltası eski güne yazılır.
     */
    fun update(s: UsageState, total: Long, dayKey: Int, monthKey: Int) {
        if (s.lastTotal < 0) {
            s.lastTotal = total
            s.dayKey = dayKey
            s.monthKey = monthKey
            return
        }

        val delta = if (total < s.lastTotal) total else total - s.lastTotal
        s.lastTotal = total

        if (monthKey != s.monthKey) {
            s.monthKey = monthKey
            s.monthBytes = 0
            // yeni ay her zaman yeni gündür
            s.dayKey = dayKey
            s.dayBytes = 0
        } else if (dayKey != s.dayKey) {
            s.dayKey = dayKey
            s.dayBytes = 0
        }

        s.dayBytes += delta
        s.monthBytes += delta
    }
}
```

```kotlin
import android.graphics.Canvas
import android.graphics.Paint
import android.graphics.Path
import android.graphics.RectF

/**
 * 240x240 yuvarlak ekran için geometri ve tekrar eden çizim parçaları.
 *
 * Tüm yardımcılar çağıranın verdiği Paint'i kullanır ve kendi içinde nesne
 * ayırmaz — Path ve RectF örnekleri burada bir kez ayrılıp yeniden kullanılır.
 */
object Geom {
    const val W = 240f
    const val H = 240f
    const val CX = 120f
    const val CY = 120f
    const val R = 120f

    private val path = Path()
    private val rect = RectF()

    /** Merkezden dikey `dy` uzaklıkta dairenin içinde kalan yarı genişlik. */
    fun halfWidthAt(dy: Float): Float {
        val d = if (dy < 0) -dy else dy
        if (d >= R) return 0f
        return Math.sqrt((R * R - d * d).toDouble()).toFloat()
    }

    /** `y` cap-top olacak şekilde yatay ortalı metin. */
    fun centerText(c: Canvas, s: CharSequence, y: Float, p: Paint, cx: Float = CX) {
        val prev = p.textAlign
        p.textAlign = Paint.Align.CENTER
        c.drawText(s, 0, s.length, cx, y - p.fontMetrics.ascent, p)
        p.textAlign = prev
    }

    fun textWidth(s: CharSequence, p: Paint): Float = p.measureText(s, 0, s.length)

    /** 5 çubuklu sinyal göstergesi. Toplam genişliği döndürür. */
    fun signalBars(c: Canvas, x: Float, y: Float, level: Int, on: Paint, off: Paint): Float {
        val bw = 4f; val gap = 3f; val hMin = 4f; val hMax = 16f
        for (i in 0 until 5) {
            val h = hMin + (hMax - hMin) * i / 4f
            rect.set(x + i * (bw + gap), y + (hMax - h), x + i * (bw + gap) + bw, y + hMax)
            c.drawRoundRect(rect, 1.5f, 1.5f, if (i < level) on else off)
        }
        return 5 * (bw + gap) - gap
    }

    /** Batarya gövdesi + ucu. Toplam genişliği döndürür. */
    fun battery(c: Canvas, x: Float, y: Float, pct: Int, outline: Paint, fill: Paint): Float {
        val w = 22f; val h = 11f
        rect.set(x, y, x + w, y + h)
        c.drawRoundRect(rect, 3f, 3f, outline)
        rect.set(x + w + 1f, y + h / 2f - 2.5f, x + w + 3f, y + h / 2f + 2.5f)
        c.drawRoundRect(rect, 1f, 1f, outline)
        val p = if (pct < 0) 0 else if (pct > 100) 100 else pct
        val inner = (w - 4f) * p / 100f
        if (inner > 0.5f) {
            rect.set(x + 2f, y + 2f, x + 2f + inner, y + h - 2f)
            c.drawRoundRect(rect, 1.5f, 1.5f, fill)
        }
        return w + 4f
    }

    /** Dolu üçgen ok. `cy` dikey merkez. */
    fun arrow(c: Canvas, cx: Float, cy: Float, size: Float, down: Boolean, p: Paint) {
        val w = size * 0.78f
        path.rewind()
        if (down) {
            path.moveTo(cx - w / 2f, cy - size / 2f)
            path.lineTo(cx + w / 2f, cy - size / 2f)
            path.lineTo(cx, cy + size / 2f)
        } else {
            path.moveTo(cx - w / 2f, cy + size / 2f)
            path.lineTo(cx + w / 2f, cy + size / 2f)
            path.lineTo(cx, cy - size / 2f)
        }
        path.close()
        c.drawPath(path, p)
    }

    /** Sayfa göstergesi noktaları. */
    fun dots(c: Canvas, count: Int, active: Int, y: Float, on: Paint, off: Paint) {
        val gap = 9f
        val x0 = CX - (count - 1) * gap / 2f
        for (i in 0 until count) {
            val r = if (i == active) 2.2f else 1.6f
            c.drawCircle(x0 + i * gap, y, r, if (i == active) on else off)
        }
    }

    /** Kilit ipucu ikonu. */
    fun padlock(c: Canvas, x: Float, y: Float, s: Float, p: Paint) {
        rect.set(x + s * 0.22f, y, x + s * 0.78f, y + s * 0.9f)
        c.drawArc(rect, 180f, 180f, false, p)
        rect.set(x, y + s * 0.45f, x + s, y + s)
        c.drawRoundRect(rect, 1.5f, 1.5f, p)
    }

    /** VPN kalkanı. */
    fun shield(c: Canvas, x: Float, y: Float, s: Float, p: Paint) {
        path.rewind()
        path.moveTo(x + s / 2f, y)
        path.lineTo(x + s, y + s * 0.26f)
        path.lineTo(x + s, y + s * 0.6f)
        path.lineTo(x + s / 2f, y + s)
        path.lineTo(x, y + s * 0.6f)
        path.lineTo(x, y + s * 0.26f)
        path.close()
        c.drawPath(path, p)
    }

    /** 12 yönünden saat yönünde ölçülen yay. */

        val inset = width / 2f
```

```kotlin
package com.kaandikec.u30plauncher.source

import java.io.BufferedReader
import java.io.InputStreamReader
import java.io.OutputStreamWriter

/**
 * Tek uzun ömürlü `su` oturumu.
 *
 * Her komut için ayrı process açmak saniyede bir çalışan bir yoklama için
 * pahalıdır; bunun yerine tek bir kabuk açıp komutları stdin'e yazarız.
 * Her komuttan sonra bir işaretçi yazdırıp ona kadar okuyarak çıktı sınırını
 * belirleriz.
 */
object RootShell {
    private const val MARK = "__U30P_EOF__"

    private var proc: Process? = null
    private var writer: OutputStreamWriter? = null
    private var reader: BufferedReader? = null
    private var failed = false

    @Synchronized
    private fun ensure(): Boolean {
        if (failed) return false
        proc?.let { if (it.isAlive) return true }
        return try {
            val p = ProcessBuilder("su").redirectErrorStream(true).start()
            proc = p
            writer = OutputStreamWriter(p.outputStream)
            reader = BufferedReader(InputStreamReader(p.inputStream))
            true
        } catch (t: Throwable) {
            failed = true
            false
        }
    }

    @Synchronized
    fun exec(cmd: String): String? {
        if (!ensure()) return null
        return try {
            val w = writer!!
            w.write(cmd)
            w.write("\necho $MARK\n")
            w.flush()
            val r = reader!!
            val sb = StringBuilder()
            while (true) {
                val line = r.readLine() ?: return null
                if (line == MARK) break
                if (sb.isNotEmpty()) sb.append('\n')
                sb.append(line)
            }
            sb.toString()
        } catch (t: Throwable) {
            close()
            null
        }
    }

    @Synchronized
    fun isAvailable(): Boolean = exec("id -u") == "0"

    @Synchronized
    fun close() {
        try { writer?.close() } catch (_: Throwable) {}
        try { reader?.close() } catch (_: Throwable) {}
        try { proc?.destroy() } catch (_: Throwable) {}
        writer = null; reader = null; proc = null
    }
}
```

```kotlin
package com.kaandikec.u30plauncher.source

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.content.IntentFilter
import android.os.BatteryManager

/** `ACTION_BATTERY_CHANGED` sticky broadcast — yalnızca öndeyken kayıtlı. */
class BatterySource(private val ctx: Context) {
    var pct: Int = -1; private set
    var currentUa: Int = 0; private set
    /** ondabir °C */
    var tempC: Int = Int.MIN_VALUE; private set

    private var onChange: (() -> Unit)? = null
    private var registered = false

    private val receiver = object : BroadcastReceiver() {
        override fun onReceive(c: Context?, i: Intent?) {
            i ?: return
            val level = i.getIntExtra(BatteryManager.EXTRA_LEVEL, -1)
            val scale = i.getIntExtra(BatteryManager.EXTRA_SCALE, 100)
            pct = if (level < 0 || scale <= 0) -1 else level * 100 / scale
            tempC = i.getIntExtra(BatteryManager.EXTRA_TEMPERATURE, Int.MIN_VALUE)
            val bm = ctx.getSystemService(Context.BATTERY_SERVICE) as? BatteryManager
            currentUa = bm?.getIntProperty(BatteryManager.BATTERY_PROPERTY_CURRENT_NOW) ?: 0
            onChange?.invoke()
        }
    }

    fun start(onChange: () -> Unit) {
        if (registered) return
        this.onChange = onChange
        ctx.registerReceiver(receiver, IntentFilter(Intent.ACTION_BATTERY_CHANGED))
        registered = true
    }

    fun stop() {
        if (!registered) return
        try { ctx.unregisterReceiver(receiver) } catch (_: Throwable) {}
        registered = false
        onChange = null
    }
}
```

```kotlin
import android.telephony.SignalStrength
import android.telephony.TelephonyCallback
import android.telephony.TelephonyManager
import com.kaandikec.u30plauncher.core.Snapshot

/**
 * Telefon durumu push ile gelir — yoklama yok.
 * `ServiceState` ve `SignalStrength` geri çağrıları ayrı ayrı tetiklenir.
 */
class TelephonySource(ctx: Context) {
    private val tm = ctx.getSystemService(Context.TELEPHONY_SERVICE) as TelephonyManager

    var operator: String = ""; private set
    var netType: String = ""; private set
    var band: Int = Snapshot.UNKNOWN; private set
    var hasService: Boolean = false; private set
    var bandwidthKhz: Int = Snapshot.UNKNOWN; private set
    var pci: Int = Snapshot.UNKNOWN; private set
    var earfcn: Int = Snapshot.UNKNOWN; private set
    var tac: Int = Snapshot.UNKNOWN; private set
    var ci: Int = Snapshot.UNKNOWN; private set
    var rsrp: Int = Snapshot.UNKNOWN; private set
    var rsrq: Int = Snapshot.UNKNOWN; private set
    var sinr: Int = Snapshot.UNKNOWN; private set
    var level: Int = 0; private set
    var permitted: Boolean = true; private set

    private var onChange: (() -> Unit)? = null
    private var callback: TelephonyCallback? = null

    private inner class Cb : TelephonyCallback(),
        TelephonyCallback.ServiceStateListener,
        TelephonyCallback.SignalStrengthsListener {

        override fun onServiceStateChanged(state: ServiceState) {
            hasService = state.state == ServiceState.STATE_IN_SERVICE
            operator = state.operatorAlphaLong?.trim() ?: ""
            netType = netTypeName(state)
            state.cellBandwidths.firstOrNull()?.let { bandwidthKhz = it }
            readCellIdentity(state)
            onChange?.invoke()
        }

        override fun onSignalStrengthsChanged(ss: SignalStrength) {
            val lte = ss.getCellSignalStrengths(CellSignalStrengthLte::class.java).firstOrNull()
            if (lte != null) {
                rsrp = lte.rsrp
                rsrq = lte.rsrq
                sinr = if (lte.rssnr == Int.MAX_VALUE) Snapshot.UNKNOWN else lte.rssnr
                level = lte.level
            }
            onChange?.invoke()
        }
    }

    private fun netTypeName(state: ServiceState): String {
        for (nri in state.networkRegistrationInfoList) {
            if (nri.isRegistered) {
                return when (nri.accessNetworkTechnology) {
                    TelephonyManager.NETWORK_TYPE_LTE -> "LTE"
                    TelephonyManager.NETWORK_TYPE_NR -> "5G"
                    TelephonyManager.NETWORK_TYPE_UMTS,
                    TelephonyManager.NETWORK_TYPE_HSPA,
                    TelephonyManager.NETWORK_TYPE_HSPAP -> "3G"
                    TelephonyManager.NETWORK_TYPE_EDGE,
                    TelephonyManager.NETWORK_TYPE_GPRS -> "2G"
                    else -> ""
                }
            }
        }
        return ""
    }

    private fun readCellIdentity(state: ServiceState) {
        for (nri in state.networkRegistrationInfoList) {
            val id = nri.cellIdentity as? android.telephony.CellIdentityLte ?: continue
            pci = id.pci
            earfcn = id.earfcn
            tac = id.tac
            ci = id.ci
            id.bands.firstOrNull()?.let { band = it }
            return
        }
    }

    fun start(onChange: () -> Unit) {
        this.onChange = onChange
        try {
            val cb = Cb()
            callback = cb
            tm.registerTelephonyCallback(Runnable::run, cb)
            permitted = true
        } catch (t: SecurityException) {
            permitted = false
        } catch (_: Throwable) {
            permitted = false
        }
    }

    fun stop() {
        callback?.let { try { tm.unregisterTelephonyCallback(it) } catch (_: Throwable) {} }
        callback = null
        onChange = null
    }
}
```

```kotlin
package com.kaandikec.u30plauncher.source

import com.kaandikec.u30plauncher.core.IfCounters
import com.kaandikec.u30plauncher.core.ProcNetParser
import java.io.File
import java.io.FileInputStream

/**
 * `/proc/net/dev`'i yeniden kullanılan bir tampona okur ve delta hızları
 * hesaplar. String üretmez.
 *
 * WAN = `sipa_eth0` (modem), VPN = `tun0`.
 */
class NetSource {
    companion object {
        private const val WAN = "sipa_eth0"
        private const val VPN = "tun0"
        private const val BUF = 8192
    }

    private val buf = ByteArray(BUF)
    private val counters = IfCounters()
    private val file = File("/proc/net/dev")

    private var lastRx = -1L
    private var lastTx = -1L
    private var lastAt = 0L

    var rxSpeed: Long = 0; private set
    var txSpeed: Long = 0; private set
    var wanTotal: Long = 0; private set
    var vpnUp: Boolean = false; private set

    private fun read(): Int {
        return try {
            FileInputStream(file).use { s ->
                var n = 0
                while (n < BUF) {
                    val r = s.read(buf, n, BUF - n)
                    if (r <= 0) break
                    n += r
                }
                n
            }
        } catch (_: Throwable) {
            0
        }
    }

    /** Bir örnek alır; hızları önceki örneğe göre günceller. */
    fun sample(nowMs: Long) {
        val len = read()
        if (len <= 0) return

        vpnUp = ProcNetParser.parse(buf, len, VPN, counters)

        if (!ProcNetParser.parse(buf, len, WAN, counters)) return
        val rx = counters.rx
        val tx = counters.tx
        wanTotal = rx + tx

        if (lastRx >= 0 && nowMs > lastAt) {
            val dt = nowMs - lastAt
            val dRx = if (rx < lastRx) rx else rx - lastRx
            val dTx = if (tx < lastTx) tx else tx - lastTx
            rxSpeed = dRx * 1000L / dt
            txSpeed = dTx * 1000L / dt
        }
        lastRx = rx; lastTx = tx; lastAt = nowMs
    }
}
```

```kotlin
package com.kaandikec.u30plauncher

import android.content.Context
import android.os.Handler
import android.os.Looper
import android.os.SystemClock
import com.kaandikec.u30plauncher.core.Snapshot
import com.kaandikec.u30plauncher.core.UsageCalc
import com.kaandikec.u30plauncher.source.BatterySource
import com.kaandikec.u30plauncher.source.NetSource
import com.kaandikec.u30plauncher.source.RootShell
import com.kaandikec.u30plauncher.source.TelephonySource
import com.kaandikec.u30plauncher.store.Prefs
import com.kaandikec.u30plauncher.store.UsageStore
import java.util.Calendar

/**
 * Kaynakları toplayıp `Snapshot` üretir.
 *
 * Yalnızca `resume()` ile `pause()` arasında çalışır. Snapshot bir öncekine
 * eşitse dinleyici çağrılmaz — çizim tetiklenmez.
 */
class DataHub(private val ctx: Context) {
    private val prefs = Prefs(ctx)
    private val usageStore = UsageStore(ctx)
    private val usage = usageStore.load()

    private val battery = BatterySource(ctx)
    private val telephony = TelephonySource(ctx)
    private val net = NetSource()

    private val handler = Handler(Looper.getMainLooper())
    private val cal: Calendar = Calendar.getInstance()

    private var listener: ((Snapshot) -> Unit)? = null
    private var running = false
    private var clientsCached = -1
    private var lastClientsAt = 0L
    private var rootChecked = false
    private var rootOk = false

    var snapshot: Snapshot = Snapshot.EMPTY
        private set

    private val tick = object : Runnable {
        override fun run() {
            if (!running) return
            net.sample(System.currentTimeMillis())
            refreshClientsIfDue()
            rebuild()
            handler.postDelayed(this, prefs.refreshMs.toLong())
        }
    }

    fun resume(l: (Snapshot) -> Unit) {
        if (running) return
        running = true
        listener = l
        battery.start(::rebuild)
        telephony.start(::rebuild)
        handler.post(tick)
    }

    fun pause() {
        if (!running) return
        running = false
        handler.removeCallbacks(tick)
        battery.stop()
        telephony.stop()
        usageStore.save(usage)
        RootShell.close()
        listener = null
    }

    /** İstemci sayısı ARP'den okunur; 5 sn'den sık okunmaz. */
    private fun refreshClientsIfDue() {
        val now = SystemClock.elapsedRealtime()
        if (now - lastClientsAt < 5000L && rootChecked) return
        lastClientsAt = now
        if (!rootChecked) {
            rootOk = RootShell.isAvailable()
            rootChecked = true
        }
        if (!rootOk) { clientsCached = -1; return }
        val out = RootShell.exec("grep -c ' br0\$' /proc/net/arp")
        clientsCached = out?.trim()?.toIntOrNull() ?: -1
    }

    private fun minuteOfDay(): Int {
        cal.timeInMillis = System.currentTimeMillis()
        return cal.get(Calendar.HOUR_OF_DAY) * 60 + cal.get(Calendar.MINUTE)
    }

    private fun dayKey(): Int {
        cal.timeInMillis = System.currentTimeMillis()
        return cal.get(Calendar.YEAR) * 366 + cal.get(Calendar.DAY_OF_YEAR)
    }

    private fun monthKey(): Int {
        cal.timeInMillis = System.currentTimeMillis()
        return cal.get(Calendar.YEAR) * 12 + cal.get(Calendar.MONTH)
    }

    private fun rebuild() {
        if (!running) return
        UsageCalc.update(usage, net.wanTotal, dayKey(), monthKey())

        val next = Snapshot(
            operator = telephony.operator,
            netType = telephony.netType,
            band = telephony.band,
            hasService = telephony.hasService,
            rsrp = telephony.rsrp,
            rsrq = telephony.rsrq,
            sinr = telephony.sinr,
            pci = telephony.pci,
            earfcn = telephony.earfcn,
            tac = telephony.tac,
            ci = telephony.ci,
            bandwidthKhz = telephony.bandwidthKhz,
            signalLevel = telephony.level,
            rxSpeed = net.rxSpeed,
            txSpeed = net.txSpeed,
            todayBytes = usage.dayBytes,
            monthBytes = usage.monthBytes,
            batteryPct = battery.pct,
            batteryUa = battery.currentUa,
            batteryTempC = battery.tempC,
            cpuTempC = Snapshot.UNKNOWN,
            vpnUp = net.vpnUp,
            clients = clientsCached,
            clockMinuteOfDay = minuteOfDay(),
            rootAvailable = rootOk,
            phonePermission = telephony.permitted
        )

        if (next != snapshot) {
            snapshot = next
            listener?.invoke(next)
        }
    }
}
```

```kotlin
/** Tüm sayfaların ortak tabanı: snapshot tutar, çizimi alt sınıfa bırakır. */
abstract class PageView(ctx: Context) : View(ctx) {
    protected var snapshot: Snapshot = Snapshot.EMPTY
        private set

    /** Yeniden çizim yalnızca içerik değiştiyse. */
    fun update(s: Snapshot) {
        if (s == snapshot) return
        snapshot = s
        invalidate()
    }

    final override fun onDraw(canvas: Canvas) {
        canvas.drawColor(Palette.BG)
        try {
            draw(canvas, snapshot)
        } catch (t: Throwable) {
            // Bir sayfanın çizim hatası launcher'ı düşürmemeli.
            android.util.Log.e("U30P", "draw failed", t)
        }
    }

    protected abstract fun draw(c: Canvas, s: Snapshot)
}
```

```kotlin
import android.graphics.Canvas
import android.graphics.Paint
import com.kaandikec.u30plauncher.core.Fmt
import com.kaandikec.u30plauncher.core.Snapshot
import com.kaandikec.u30plauncher.ui.Geom

/**
 * Varsayılan tema: süssüz beş satır, en büyük tipografi.
 *
 * Tüm Paint'ler burada bir kez ayrılır; `draw` içinde allocation yoktur.
 */
object StackedTheme : Theme {
    private val clock = paint(13f, Palette.DIM2)
    private val operator = paint(17f, Palette.FG)
    private val meta = paint(11f, Palette.DIM)
    private val unit = paint(11f, Palette.DIM2)
    private val down = paint(38f, Palette.DOWN)
    private val up = paint(38f, Palette.UP)
    private val barOn = fill(Palette.FG)
    private val barOff = fill(Palette.TRACK)
    private val battOutline = stroke(Palette.DIM, 1f)
    private val battFill = fill(Palette.DOWN)
    private val shieldPaint = fill(Palette.DOWN)
    private val lockPaint = stroke(Palette.DIM2, 1.5f)
    private val dotOn = fill(Palette.FG)
    private val dotOff = fill(Palette.TRACK)

    private fun paint(size: Float, color: Int) = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        textSize = size; this.color = color
    }
    private fun fill(color: Int) = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        this.color = color; style = Paint.Style.FILL
    }
    private fun stroke(color: Int, w: Float) = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        this.color = color; style = Paint.Style.STROKE; strokeWidth = w
    }

    override fun draw(c: Canvas, s: Snapshot, sb: StringBuilder) {
        // saat
        sb.setLength(0)
        val h = s.clockMinuteOfDay / 60
        val m = s.clockMinuteOfDay % 60
        if (h < 10) sb.append('0'); sb.append(h); sb.append(':')
        if (m < 10) sb.append('0'); sb.append(m)
        Geom.centerText(c, sb, 26f, clock)

        // operatör
        sb.setLength(0)
        sb.append(if (s.operator.isNotEmpty()) s.operator else "SIM yok")
        Geom.centerText(c, sb, 48f, operator)

        // sinyal çubuğu + teknoloji + RSRP
        sb.setLength(0)
        sb.append(if (s.netType.isNotEmpty()) s.netType else "—")
        sb.append("  •  ")
        if (s.rsrp == Snapshot.UNKNOWN) sb.append("—") else { sb.append(s.rsrp); sb.append(" dBm") }
        val barsW = 32f
        val textW = Geom.textWidth(sb, meta)
        val x0 = Geom.CX - (barsW + 8f + textW) / 2f
        Geom.signalBars(c, x0, 72f, s.signalLevel, barOn, barOff)
        c.drawText(sb, 0, sb.length, x0 + barsW + 8f, 72f + 2f - meta.fontMetrics.ascent, meta)

        // hızlar
        drawSpeed(c, sb, 100f, s.rxSpeed, down, true)
        drawSpeed(c, sb, 144f, s.txSpeed, up, false)

        sb.setLength(0)
        sb.append(Fmt.speedUnit(if (s.rxSpeed > s.txSpeed) s.rxSpeed else s.txSpeed))
        Geom.centerText(c, sb, 184f, unit)

        drawBottomStrip(c, s)
    }

    private fun drawSpeed(c: Canvas, sb: StringBuilder, y: Float, v: Long, p: Paint, isDown: Boolean) {
        sb.setLength(0)
        Fmt.appendSpeedValue(sb, v)
        val w = Geom.textWidth(sb, p)
        val x = Geom.CX - (w + 22f) / 2f
        Geom.arrow(c, x + 8f, y + 14f, 20f, isDown, p)
        c.drawText(sb, 0, sb.length, x + 22f, y - p.fontMetrics.ascent, p)
    }

    /** Batarya her zaman; VPN yalnızca bağlıyken; istemci yalnızca > 0 iken. */
    private fun drawBottomStrip(c: Canvas, s: Snapshot) {
        val y = 202f
        var width = 26f
        if (s.vpnUp) width += 15f
        if (s.clients > 0) width += 20f
        width += 21f  // kilit + boşluk

        var x = Geom.CX - width / 2f
        battFill.color = when {
            s.batteryPct < 0 -> Palette.DIM2
            s.batteryPct > 30 -> Palette.DOWN
            s.batteryPct > 15 -> Palette.WARN
            else -> Palette.ERR
        }
        x += Geom.battery(c, x, y, s.batteryPct, battOutline, battFill) + 8f

        if (s.vpnUp) {
            Geom.shield(c, x, y - 1f, 11f, shieldPaint)
            x += 15f
        }
        if (s.clients > 0) {
            meta.color = Palette.DIM
            c.drawText(s.clients.toString(), x, y + 9f, meta)
            x += 20f
        }
        Geom.padlock(c, x, y - 1f, 10f, lockPaint)
    }

    fun drawDots(c: Canvas, count: Int, active: Int) =
        Geom.dots(c, count, active, 222f, dotOn, dotOff)
}
```

```kotlin
package com.kaandikec.u30plauncher.ui

import android.content.Context
import android.view.GestureDetector
import android.view.MotionEvent
import android.widget.FrameLayout
import com.kaandikec.u30plauncher.core.Snapshot

/**
 * ViewPager2 yerine elle yazılmış sayfa anahtarı.
 *
 * Tek seferde tek çocuk görünür; kaydırma animasyonu yoktur. 30 Hz panelde
 * animasyon görsel kazanç sağlamaz ama her karede çizim maliyeti getirir.
 */
class Pager(ctx: Context) : FrameLayout(ctx) {
    private val pages = ArrayList<PageView>(3)
    private var current = 0
    private var latest: Snapshot = Snapshot.EMPTY

    /** Yatay kaydırma bu eşiği aşarsa sayfa değişir. */
    private val swipeThreshold = 40f

    var onLongPress: (() -> Unit)? = null

    private val detector = GestureDetector(ctx, object : GestureDetector.SimpleOnGestureListener() {
        override fun onDown(e: MotionEvent) = true

        override fun onFling(
            e1: MotionEvent?, e2: MotionEvent, vx: Float, vy: Float
        ): Boolean {
            e1 ?: return false
            val dx = e2.x - e1.x
            if (Math.abs(dx) < swipeThreshold) return false
            if (Math.abs(dx) < Math.abs(e2.y - e1.y)) return false
            go(if (dx < 0) current + 1 else current - 1)
            return true
        }

        override fun onLongPress(e: MotionEvent) {
            onLongPress?.invoke()
        }
    })

    fun setPages(list: List<PageView>) {
        removeAllViews()
        pages.clear()
        pages.addAll(list)
        for (p in pages) addView(p)
        current = 0
        applyVisibility()
    }

    fun update(s: Snapshot) {
        latest = s
        pages.getOrNull(current)?.update(s)
    }

    var index: Int
        get() = current
        set(v) = go(v)

    private fun go(target: Int) {
        if (pages.isEmpty()) return
        val n = pages.size
        val next = ((target % n) + n) % n
        if (next == current) return
        current = next
        applyVisibility()
        pages[current].update(latest)
    }

    private fun applyVisibility() {
        for (i in pages.indices) {
            pages[i].visibility = if (i == current) VISIBLE else GONE
        }
    }

    override fun onTouchEvent(event: MotionEvent): Boolean {
        detector.onTouchEvent(event)
        return true
    }
}
```

```kotlin
package com.kaandikec.u30plauncher

import com.kaandikec.u30plauncher.source.RootShell

/**
 * Ayrıcalıklı işlemler. Hepsi tek root kabuğundan geçer — uygulamanın
 * WRITE_SETTINGS / MODIFY_PHONE_STATE gibi özel izinlere ihtiyacı olmaz.
 *
 * Bu cihazda `svc data` ve `svc wifi` yok; veriyi kesmenin tek yolu uçak modu.
 */
object Actions {
    val TIMEOUTS = intArrayOf(15_000, 60_000, 300_000, Int.MAX_VALUE)

    fun reboot(): Boolean = RootShell.exec("reboot") != null

    fun airplaneOn(): Boolean =
        RootShell.exec("cmd connectivity airplane-mode")?.contains("enabled") == true

    fun setAirplane(on: Boolean): Boolean =
        RootShell.exec("cmd connectivity airplane-mode " + if (on) "enable" else "disable") != null

    fun screenTimeout(): Int =
        RootShell.exec("settings get system screen_off_timeout")?.trim()?.toIntOrNull() ?: 60_000

    fun setScreenTimeout(ms: Int): Boolean =
        RootShell.exec("settings put system screen_off_timeout $ms") != null
}
```

```kotlin
package com.kaandikec.u30plauncher.ui

import android.content.Context
import android.graphics.Canvas
import android.graphics.Paint
import android.os.SystemClock
import android.view.MotionEvent
import com.kaandikec.u30plauncher.Actions
import com.kaandikec.u30plauncher.core.Snapshot

/**
 * Yıkıcı işlemler kilit açıkken bile 1 sn basılı tutma ister; dış kenarda
 * dolan halka geri bildirim verir, parmak kalkınca işlem iptal olur.
 */
class ActionsPage(ctx: Context) : PageView(ctx) {
    companion object {
        private const val HOLD_MS = 1000L
        private val ROW_Y = floatArrayOf(66f, 114f, 162f)
    }

    private val labelPaint = paint(14f, Palette.FG)
    private val hintPaint = paint(10f, Palette.DIM2)
    private val titlePaint = paint(10f, Palette.DIM2)
    private val ringColors = intArrayOf(Palette.ERR, Palette.WARN, Palette.UP)
    private val bullet = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE; strokeWidth = 2f
    }
    private val progress = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE; strokeCap = Paint.Cap.ROUND
    }

    private var holdingRow = -1
    private var holdStart = 0L
    private var timeoutMs = 60_000

    var onActionDone: ((String) -> Unit)? = null

    private fun paint(size: Float, color: Int) = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        textSize = size; this.color = color
    }

    fun refreshState() { timeoutMs = Actions.screenTimeout() }

    override fun draw(c: Canvas, s: Snapshot) {
        Geom.centerText(c, "AKSİYONLAR", 20f, titlePaint)

        for (i in 0 until 3) {
            bullet.color = ringColors[i]
            c.drawCircle(52f, ROW_Y[i] + 2f, 8f, bullet)
            labelPaint.color = if (s.rootAvailable) Palette.FG else Palette.DIM2
            c.drawText(rowLabel(i), 72f, ROW_Y[i] + 7f, labelPaint)
        }

        if (!s.rootAvailable) {
            Geom.centerText(c, "root yok", 200f, hintPaint)
            return
        }

        if (holdingRow >= 0) {
            val f = ((SystemClock.uptimeMillis() - holdStart).toFloat() / HOLD_MS).coerceIn(0f, 1f)
            progress.color = ringColors[holdingRow]
            Geom.arcRing(c, 116f, 3f, 0f, 360f * f, progress)
            if (f >= 1f) fire(holdingRow) else postInvalidateOnAnimation()
        } else {
            Geom.centerText(c, "1 sn basılı tut", 200f, hintPaint)
        }
    }

    private fun rowLabel(i: Int): String = when (i) {
        0 -> "Yeniden başlat"
        1 -> "Veri kes"
        else -> "Ekran: " + timeoutLabel(timeoutMs)
    }

    private fun timeoutLabel(ms: Int): String = when (ms) {
        15_000 -> "15 sn"
        60_000 -> "1 dk"
        300_000 -> "5 dk"
        else -> "kapanmaz"
    }

    private fun fire(row: Int) {
        holdingRow = -1
        when (row) {
            0 -> { Actions.reboot(); onActionDone?.invoke("Yeniden başlatılıyor") }
            1 -> {
                val on = Actions.airplaneOn()
                Actions.setAirplane(!on)
                onActionDone?.invoke(if (on) "Veri açıldı" else "Veri kesildi")
            }
        }
        invalidate()
    }

    /** Ekran süresi zararsız olduğu için basılı tutma istemez. */
    private fun cycleTimeout() {
        val idx = Actions.TIMEOUTS.indexOf(timeoutMs)
        val next = Actions.TIMEOUTS[(if (idx < 0) 1 else idx + 1) % Actions.TIMEOUTS.size]
        Actions.setScreenTimeout(next)
        timeoutMs = next
        invalidate()
    }

    private fun rowAt(y: Float): Int {
        for (i in 0 until 3) if (Math.abs(y - ROW_Y[i]) < 22f) return i
        return -1
    }

    override fun onTouchEvent(event: MotionEvent): Boolean {
        if (!snapshot.rootAvailable) return true
        when (event.actionMasked) {
            MotionEvent.ACTION_DOWN -> {
                val row = rowAt(event.y)
                if (row == 2) { cycleTimeout(); return true }
                if (row >= 0) {
                    holdingRow = row
                    holdStart = SystemClock.uptimeMillis()
                    invalidate()
                }
            }
            MotionEvent.ACTION_UP, MotionEvent.ACTION_CANCEL -> {
                if (holdingRow >= 0) { holdingRow = -1; invalidate() }
            }
        }
        return true
    }
}
```

```kotlin
package com.kaandikec.u30plauncher

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import com.kaandikec.u30plauncher.store.Prefs

/**
 * adb'den yapılandırma. `android.permission.DUMP` ile korunur — shell ve root
 * bu izne sahiptir, normal uygulamalar değildir.
 *
 * Manifest'te tanımlı olması maliyet getirmez: tetiklenmedikçe süreç
 * başlatmaz, uygulamayı ayakta tutmaz.
 */
class CfgReceiver : BroadcastReceiver() {
    override fun onReceive(ctx: Context, intent: Intent) {
        val prefs = Prefs(ctx)
        intent.getStringExtra("theme")?.let {
            prefs.theme = when (it.lowercase()) {
                "arc" -> Prefs.THEME_ARC
```

```kotlin
import android.graphics.Canvas
import android.graphics.Paint

/** Çemberi sinyal göstergesi olarak kullanır; hero anlık indirme hızıdır. */
object ArcTheme : Theme {
    private val track = arc(Palette.TRACK)
    private val level = arc(Palette.DOWN)
    private val operator = text(14f, Palette.FG)
    private val meta = text(11f, Palette.DIM)
    private val hero = text(52f, Palette.FG)
    private val unit = text(12f, Palette.DIM)
    private val upPaint = text(13f, Palette.UP)
    private val downFill = fill(Palette.DOWN)
    private val upFill = fill(Palette.UP)
    private val clock = text(13f, Palette.DIM)
    private val hair = Paint().apply { color = Palette.HAIRLINE; strokeWidth = 1f }
    private val battOutline = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE; strokeWidth = 1f; color = Palette.DIM
    }
    private val battFill = fill(Palette.DOWN)

    private fun text(s: Float, c: Int) = Paint(Paint.ANTI_ALIAS_FLAG).apply { textSize = s; color = c }
    private fun fill(c: Int) = Paint(Paint.ANTI_ALIAS_FLAG).apply { color = c }
    private fun arc(c: Int) = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE; color = c; strokeCap = Paint.Cap.ROUND
    }

    override fun draw(c: Canvas, s: Snapshot, sb: StringBuilder) {
        Geom.arcRing(c, 118f, 5f, 225f, 270f, track)
        Geom.arcRing(c, 118f, 5f, 225f, 270f * (s.signalLevel / 4f), level)

        sb.setLength(0); sb.append(if (s.operator.isNotEmpty()) s.operator else "SIM yok")

        sb.setLength(0)
        sb.append(if (s.netType.isNotEmpty()) s.netType else "—")
        if (s.band != Snapshot.UNKNOWN) { sb.append("  B"); sb.append(s.band) }
        Geom.centerText(c, sb, 47f, meta)

        Geom.centerText(c, sb, 78f, hero)

        sb.setLength(0); sb.append(Fmt.speedUnit(s.rxSpeed))
        Geom.centerText(c, sb, 133f, unit)
        Geom.arrow(c, Geom.CX - 34f, 139f, 11f, true, downFill)

        sb.setLength(0); Fmt.appendSpeedValue(sb, s.txSpeed)
        sb.append(' '); sb.append(Fmt.speedUnit(s.txSpeed))
        val w = Geom.textWidth(sb, upPaint)
        val x = Geom.CX - (w + 12f) / 2f
        Geom.arrow(c, x + 5f, 162f, 10f, false, upFill)
        c.drawText(sb, 0, sb.length, x + 12f, 155f - upPaint.fontMetrics.ascent, upPaint)

        c.drawLine(70f, 180f, 170f, 180f, hair)

        sb.setLength(0)
        val h = s.clockMinuteOfDay / 60; val m = s.clockMinuteOfDay % 60
        if (h < 10) sb.append('0'); sb.append(h); sb.append(':')

                         else if (s.batteryPct > 15) Palette.WARN else Palette.ERR
        Geom.battery(c, bx + tw + 14f, 194f, s.batteryPct, battOutline, battFill)
    }
}
```

```kotlin
package com.kaandikec.u30plauncher

import android.content.Context
import android.content.Intent
import java.io.File
import java.io.PrintWriter

/**
 * Bir launcher çökerse cihaz kullanılamaz hale gelir. Süreci öldürmek yerine
 * hatayı diske yazıp Activity'yi yeniden başlatırız.
 *
 * Yeniden başlatma döngüsüne girmemek için 10 saniye içinde ikinci bir çökme
 * olursa varsayılan davranışa bırakılır.
 */
object CrashGuard {
    private const val LOG = "crash.log"
    private var lastCrashAt = 0L

    fun install(ctx: Context) {
        val prev = Thread.getDefaultUncaughtExceptionHandler()
        Thread.setDefaultUncaughtExceptionHandler { thread, error ->
            val now = System.currentTimeMillis()
            val looping = now - lastCrashAt < 10_000L
            lastCrashAt = now
            try {
                PrintWriter(File(ctx.filesDir, LOG)).use { w ->
                    w.println(now.toString())
                    error.printStackTrace(w)
                }
            } catch (_: Throwable) {}

            if (looping) {
                prev?.uncaughtException(thread, error)
                return@setDefaultUncaughtExceptionHandler
            }

            try {
                val i = Intent(ctx, LauncherActivity::class.java)
                i.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK)
                ctx.startActivity(i)
            } catch (_: Throwable) {}

            android.os.Process.killProcess(android.os.Process.myPid())
        }
    }
}
```

`LauncherActivity.onCreate` başına `CrashGuard.install(applicationContext)` ekle.
